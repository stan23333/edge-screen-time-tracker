Capture

Screenshots require the extension's all-URLs permission and are taken only when the blocked page is visible. The image is sent to the configured vision-capable summary model and is not stored. Leave the domain list empty to allow all blocked domains.

Downloads fallback

The stable fallback saves files under your browser Downloads folder, for example Downloads/browser-tracker.

If your browser supports folder access, the extension will write to the chosen folder first and fall back to Downloads if permission is unavailable.
